# Reference imagery — rights note

`dk92-crowd.jpg` — the iconic **Denmark Euro '92** fan celebration (a sea of
Danmark flags). Used here as the hero/backdrop in the rebrand reference mockups
because it *is* the thesis: the room/the city converging, "find your people."

**Rights:** this is a **copyrighted press photograph** (Ritzau / Getty / Polfoto
class), **not** a free/Commons image. It is included only as a *reference mockup*
to show the creative direction. **It must NOT ship in the product as-is.**

For production, the hero image needs to be either:
1. **licensed** — likely via Ritzau Scanpix / the Danish FA (DBU) / a national
   archive (a national-treasure photo a Danish football app can plausibly clear),
   or
2. **replaced** with a free/Commons-licensed equivalent (the project's standing
   discipline — see `docs/ATTRIBUTION.md`; every shipped image is free-licensed
   with attribution).

Everything else in these mockups (type, palette, layout, the lime-node motif) is
original and carries no rights encumbrance.
